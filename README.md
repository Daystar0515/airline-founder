# 航空公司創始人（Airline Founder）— v1.0.0-rc

在真實的全球機場網路上創立航空公司、設立樞紐、購買或租賃飛機、自訂艙等、開設航線，看著自己的飛機在地圖上飛行並賺錢。

v0.2 新增：A/B/C/D 級檢查與自動維修政策、維修棚廠、機械延誤、緊急轉降、失事與賠償、民航主管機關稽查、乘客滿意度與社會評價、自訂 500×500 企業標誌。舊版存檔會自動升級。

v0.3 新增：7 種創始人背景（富二代、工程技師、職業經理人與董事會五年協議等）、員工名冊與薪資、士氣與招募離職、工會訴求與罷工、排班政策、各艙等餐飲與空廚供應商、自建空廚。

v0.3.1 新增：NASA Blue Marble 衛星底圖、寬體／窄體／螺旋槳三種白色飛機圖示、開航可搜尋任意目的地、機型限制（COMAC 限中國大陸境內、A380 限大型機場、寬體機不能起降小型機場）、自動維修總開關與單機設定、C／D 檢自動調機到有棚廠的樞紐。

v0.4 新增：損益表、資產負債表、現金流量表（每月自動勾稽）、飛機與設施折舊、20% 營所稅與虧損扣抵、機身險與責任險、銀行信用貸款與飛機抵押貸款（信用評等決定利率與額度）、逾期與破產、股票上市、股價、股利、現金增資、股東會、三級自建空廚；依裝置自動切換手機版或電腦版，也可在「總覽 › 公司設定」手動指定。

v0.4.1 修正：興建自建空廚後現金、營收、報表變成 NaN 的錯誤；載入受影響的舊存檔時會自動修復。

v0.4.2 新增：社群媒體（新聞、自媒體、企業、民眾四類貼文每週刷新，可回應話題或自行發文，影響社會評價、訂位、票價收益、士氣與股價）；全新淺色介面（左側圖示導覽列、浮動卡片、手機版九個分頁一次排開）；地圖換成 Natural Earth I 底圖（解析度為舊版 4 倍），放大後改用 10m 向量海岸線與國界，放大到機場等級可看到真實跑道。所有媒體、帳號與企業名稱皆為虛構。

v0.5.0 改善：地圖拖曳與縮放時先移動上一張畫面的快照、停手才完整重畫；高精度海岸線分成 10°×10° 格子與兩種精度，只處理畫面內的格子，並改成放大時才載入（修正放大到機場等級會卡住數十秒的問題）；圖磚記憶體上限、樣式與時區計算快取、面板內容沒變就不重畫、存檔最快每 15 秒一次。新增自動產生的航空公司標誌：沒有上傳時依公司名稱、代碼與企業色從八種原創樣式產生，可隨時換一個樣式。

v0.6.0 新增：政府合約（偏遠航線補貼、政府包機、撤僑任務、公務運輸標案；價格 50%＋品質 50% 的投標評分，品質看社會評價、飛安、準點、信用與員工士氣；履約不佳會被扣款或解約）；開航時自訂航班編號、依每架閒置飛機的艙等與最佳票價推薦執飛飛機（沒有閒置飛機時推薦機型）；依艙等自動最佳定價（每天重新計算，手動拖曳票價就改回手動）；購買或租賃時自訂飛機編號，之後也能改編號。票價高於參考價時旅客更敏感，滿意度也會略降。

v0.6.1 新增：需求拆成觀光客與商務客。觀光客重 CP 值、對票價敏感；商務客幾乎不在意票價，但看重座椅等級、貴賓室、班次密度、準點與社會評價。依 2024 年真實旅客統計加上「觀光熱度」（例如台港、台越、韓越）與「旅遊嚮往度」（例如台灣出國旅客有 36% 去日本，觀光客較不在意票價）；依 GaWC 2024 世界城市分級與各國商務旅客傾向決定商務比例。修正對話框內表格被壓成看不見的問題。資料整理在 `tools/build_demand.py`。

v0.6.2 調整：時間以「一天」為最小單位推進（每 4／2／1 秒一天，或按「下一天」跑完今天後暫停；按暫停會跑完當天才停，飛機在一天之內照常飛）。機場依最長跑道分成三級：大型（≥2,990 m，可起降 A380、747、777、A350）、中型（≥2,490 m，最多起降 A330、787、767）、小型（只能起降螺旋槳、支線客機與 A320／737 系列）。二手飛機改由「二手市場」每季第一天刷新 10–15 架，每架機齡、機況、原艙位配置不同，價格也不同；機況越差越容易故障、維修費越高。新機交機前可免費設定艙位，之後改艙位要花錢送廠改裝、停飛數天；艙位可存成「艙位設定」，之後購買或租賃同機型時直接套用。可一次訂購 1–20 架：沒有自訂編號時依序編為「公司代碼-001、002…」，自訂時第二架起把第一架編號最後的數字加 1（B-58201 → B-58202）。

v0.6.3 新增：機場類型。國際機場可飛國內線與世界各地的國際線；國內線機場只能飛國內線（例如大阪伊丹、金門、澎湖）；限定國際機場可飛國內線，但國際線只限特定航點（例如台北松山只能飛羽田、金浦、虹橋與部分中國大陸城市）。依 OpenFlights 2014 年真實航線判定（`tools/build_roles.py`，需要 `of/data/routes.dat`）；台灣、香港、澳門、中國大陸各自算一個地區。舊存檔已開的航線可繼續營運，標示為「舊制航線」。

v0.6.4 新增：會員方案（在「服務」分頁）。等級數（1–5）、名稱、年費與每一級的福利都由玩家決定；10 種福利各有 3 級，貴賓室、優先登機、保證座位、升等券較吸引商務客，票價折扣、行李、選位、生日禮較吸引觀光客。年費是固定收入，會員優先搭自家航班（攬客率加成最多 +40%），但每次搭機都會用掉福利成本；編輯時即時估算加入率、會員數與每月收支。飛機整修：機況不好的飛機可以整修，但不會回到 100%（上限 95% 起，每 6,000 飛行小時降 1%，最低 85%）。機況 80% 以上是輕度整修（任何樞紐可自修）、65–80% 中度整修（需 1 級維修棚廠）、65% 以下重度整修（需 2 級維修棚廠）；棚廠等級不夠就委外，費用 ×1.5、工期 ×1.25。

v0.7.0 新增：真實航空公司競爭對手（全球 596 家，2026 年真實航網；班次與機隊依市場估算）。同航線的對手會稀釋你的攬客力；你削價搶客，樞紐航空與低成本航空會降價迎戰，搶到它樞紐航線的旅客，它會加班。真實航空公司不會破產，也不會有醜聞或飛安事故。新增「競爭」分頁、機場的航空公司清單、開航視窗的競爭對手與市占估算、地圖上顯示任一航空公司的航網。飛行路徑改為接近現實：避開烏克蘭、北韓、敘利亞、利比亞、葉門空域；歐美日韓台等國的航空公司避開俄羅斯與白俄羅斯；台灣與中國大陸之間走兩岸北線或南線；繞飛會增加飛行時間、油耗與所需航程。機場類型改用 2026 年航線資料判定。新增創始人背景「首富」（起始資金約 40.5 億美元）。

v0.8.0 新增：房主制多人連線（最多 4 人在同一個世界競爭；總覽頁建立或加入房間）。每個人在自己的瀏覽器經營自己的航空公司，房主控制時間（大家最多差一天），同航線的玩家會互相搶旅客，二手市場全房間共用。連線用 PeerJS 的免費配對服務（需要網路，載入 cdn.jsdelivr.net 的 peerjs@1.5.4），也可以選「本機測試」在同一台電腦的分頁之間連線。主要航空公司（約 90 家）改用真實機隊數校正班次。地圖可切換「航線＋飛機／只顯示航線／只顯示飛機」。財務新增「航線排行」：前十大賺錢航線（本月、上月、近 3 個月）。航線需求旺盛或不足時，每週提醒換大或換小機型：機隊有合適的閒置飛機可一鍵換上，沒有的話建議購買或租賃的機型。

v0.9.0 新增：機隊可依機型、狀態篩選，用飛機編號、航班編號或航點搜尋，並依編號、機型、航班編號、機況、座位或飛行時數排序；航線可用國家、城市、航班編號或機型搜尋，依國家分組或篩選。開航時，已開發的航線標示「已開發」與執飛機型（例如 A321neo×2），不能重複開設，可直接前往該航線。新增「聯盟」分頁：星空聯盟、寰宇一家、天合聯盟（成員依 2026 年 10 月維基百科），符合條件可申請加入（審查 60 天、整合 90 天）；也可以自創聯盟，邀請還沒加入三大聯盟的 AI 航空公司或連線的朋友，AI 也會主動申請加入。聯盟效益：飛往盟友樞紐的轉機旅客、常客互惠（商務客）、貴賓室共享、同航線盟友改為合作（不打價格戰）；自創聯盟的效益依聯盟航網大小計算。股市改為大盤多空循環＋波動群聚＋航空類股消息＋個股波動，每月結算後依獲利跳空；新增「股市投資」：可買賣 54 家上市航空集團與連線朋友公司的股票（單一公司最多 15%），盟友與航空集團也會買進你的股票，盟友持股在股東會支持你。融資新增公司債（3／5／7／10 年期，每月付息、到期還本，需 BB 以上）。

v1.0.0-rc（正式版候選）新增：5 個存檔欄位、自動存檔頻率可調、每月備份、存檔壓縮、匯出／匯入存檔檔案（iPhone 用分享選單存到「檔案」）、程式出錯時暫停並保護存檔；遊戲標誌、標題畫面、遊戲選單（點左上角公司名稱）、「關於」頁（資料來源、授權、更新紀錄）；可加到主畫面（PWA，離線遊玩）。新手引導（9 個步驟，手機與電腦版都能用）、各分頁的說明按鈕、遊戲百科（19 個主題，可搜尋）、設定頁（版面、地圖、自動存檔、通知多寡）。34 個成就、公司大事記、經營統計與遊戲結束時的經營回顧。後期效能大幅改善（160 架、80 條航線時每遊戲日的模擬時間從約 6.8 秒降到約 0.1 秒）。多人連線：只傳有變動的資料、切到背景的玩家標為「暫離」不拖住房間並在回來時自動追上、斷線自動重連（最多 4 次）、「測試我的網路」。

## 怎麼玩

- **直接玩**：在 Windows 上雙擊 `dist/airline-founder.html`（或 `dist/index.html`），用瀏覽器開啟即可，不需要安裝任何東西。`dist/tiles/` 資料夾是衛星底圖，要和網頁放在一起。存檔會自動存在瀏覽器裡，也可以從選單匯出成檔案。
- **放上 GitHub Pages**：把整個 `dist/` 資料夾的內容（`index.html`、`manifest.webmanifest`、`sw.js`、`icons/`、`tiles/`）放到 GitHub 儲存庫，在 Settings → Pages 指定那個資料夾即可。在正式網站上可以「加入主畫面」並離線遊玩。想在錯誤畫面與「關於」顯示回報按鈕，把 `game/js/version.js` 的 `G.REPORT_URL` 改成你的 GitHub Issues 網址再重新打包。
- **地圖底圖**：內建 Natural Earth I（21600×10800，公有領域），切成 5 層、每層 1024 像素的圖磚。想換其他等距圓柱投影的全球影像（例如 NASA Blue Marble 21600×10800），執行 `python tools/build_tiles.py <影像檔> game/tiles`，再重新打包。放大超過一定倍率後，遊戲會載入 `tiles/detail-0.js`、`tiles/detail-1.js` 的 10m 向量海岸線與國界（`tools/build_detail.py` 產生，依 10°×10° 分格）和 `game/data/runways.js` 的跑道（`tools/build_runways.py` 產生）。
- **改程式後重新打包**：安裝 Python 後，在專案資料夾執行 `python tools/bundle.py .`，會重新產生 `dist/` 裡的網頁、可加到主畫面的設定檔、離線快取與圖示。
- **更新機場資料**：重新下載三份公開資料（見下方「資料來源」）放到對應資料夾，再執行 `python tools/build_data.py . game/data`。

操作（電腦版）：滑鼠拖曳移動地圖、滾輪或右下角 +／− 縮放、點選機場查看資訊；空白鍵暫停或繼續時間（暫停會跑完當天）；再點一次目前的分頁可收起面板。
操作（手機版）：單指拖曳、雙指縮放；底部分頁列切換面板，再點一次目前的分頁收起面板，點面板上方的把手展開成全螢幕。

## 桌面版（選用，原本為上架 Steam 準備）

1. 安裝 Node.js，在 `desktop/` 執行 `npm install`。
2. 把 `dist/airline-founder.html` 和 `dist/tiles/` 資料夾複製到 `desktop/game/`。
3. `npm start` 測試桌面版，`npm run dist` 產生 Windows 執行檔。
4. 之後接上 steamworks.js（成就、雲端存檔），再透過 Steamworks 上傳。

- 機場與跑道：OurAirports（公有領域）— github.com/davidmegginson/ourairports-data
- 機場時區：OpenFlights — github.com/jpatokal/openflights
- 機場類型與真實航空公司航網：Jonty/airline-route-data（2026 年，`src-data/airline_routes.json`；`tools/build_roles.py`、`tools/build_carriers.py`）；沒有這個檔案時，機場類型改用 OpenFlights routes.dat（2014 年，ODbL）
- 航空公司母國：OpenFlights airlines.dat（ODbL）
- 真實機隊數：維基百科「List of largest airlines in Asia／Europe／Oceania／Africa」與各航空公司條目（2025–2026 年版本）
- 航空聯盟成員：維基百科 Star Alliance／Oneworld／SkyTeam 條目（2026 年 10 月）
- 多人連線：PeerJS（MIT 授權，執行時從 jsDelivr 載入）
- 封閉空域：Natural Earth 50m 國界（`tools/build_airspace.py`）
- 國界、城市人口、各國 GDP 與中文國名：Natural Earth（公有領域）— github.com/nvkelso/natural-earth-vector
- 宵禁：設計者提供（高雄小港）、維基百科 Night flying restrictions 條目，其餘標註「待校對」
- 機型規格與價格：各製造商公開規格的近似值
- 雙邊旅客統計（2024）：日本 JNTO、台灣交通部觀光署、韓國觀光公社、泰國、越南、新加坡 STB、香港旅發局、西班牙 INE Frontur
- 國際商務城市等級：GaWC 2024 World Cities — gawc.lboro.ac.uk
- 地圖底圖：Natural Earth I 21600×10800（公有領域）— github.com/nvkelso/natural-earth-raster
- 高精度海岸線與國界：Natural Earth 10m（公有領域）
- 跑道位置：OurAirports runways.csv（公有領域）
